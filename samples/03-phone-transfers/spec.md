# Переводы по номеру телефона в другие банки

## Новый функционал

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Исходящие переводы по номеру телефона клиентам других банков |
| **Продукт** | Мобильный банк для физических лиц |
| **Бизнес-процесс** | Переводы физических лиц |
| **Business owner / Product owner / Аналитик** | Директор розничного бизнеса / владелец продукта «Переводы» / бизнес-аналитик команды переводов |
| **Тип работы** | Новый функционал |
| **Влияние на ИС** | Мобильный банк, сервис переводов, АБС, антифрод, шлюз СБМП |
| **Задача в JIRA** | PAY-2148 |

### Цели
Клиенты Банка могут отправлять и получать переводы по номеру телефона между Банком и другими банками — участниками СБМП, не вводя номер карты или IBAN. Целевой показатель — 150 000 исходящих переводов в месяц через шесть месяцев после запуска.

### Архитектура решения
Мобильное приложение → сервис переводов → антифрод → АБС (блокировка суммы) → шлюз СБМП → банк получателя. Ответ банка получателя возвращается по той же цепочке.

### Дизайн процесса UI
Платежи → Переводы → «По номеру телефона».

* Экран 1: ввод номера или выбор из контактов.
* Экран 2: выбор банка получателя, имя получателя, сумма, комиссия, карта или счёт списания.
* Экран 3: подтверждение.
* Экран 4: статус перевода.

Интерфейс должен быть интуитивно понятным. Макеты — в работе у дизайнера, ссылка будет добавлена.

### Требования к изменениям

#### BPMN схема процесса
Ввод номера → поиск получателя в СБМП → выбор банка → ввод суммы → расчёт комиссии → антифрод-проверка → подтверждение клиентом → блокировка суммы в АБС → отправка в СБМП → получение статуса → списание или разблокировка → уведомление клиента.

#### Функциональные требования
* **Ф-1.** Переводить могут клиенты — резиденты РК с активной картой или текущим счётом в тенге. Источник списания клиент выбирает на экране 2.
* **Ф-2.** Номер получателя вводится вручную или выбирается из контактов. Принимаются только номера казахстанских операторов в формате +7 7XX XXX XX XX: СБМП обслуживает только такие номера.
* **Ф-3.** По номеру телефона сервис запрашивает в СБМП список банков получателя. Первым показывается банк, который получатель выбрал в СБМП как основной; если основной банк не выбран, банки показываются по алфавиту.
* **Ф-4.** СБМП возвращает имя бенефициара в маскированном виде: имя и первая буква фамилии, например «Имя Ф.». В таком виде оно и показывается отправителю.
* **Ф-5.** Сумма одного перевода — от 100 ₸ до 1 000 000 ₸ включительно. Суммарный лимит исходящих переводов по номеру телефона — 3 000 000 ₸ за календарный день (UTC+5) на клиента.
* **Ф-6.** Переводы на сумму до 200 000 ₸ в календарный месяц бесплатны, переводы свыше 200 000 ₸ — комиссия 0,95 %, минимум 100 ₸. Комиссия показывается клиенту до подтверждения перевода.
* **Ф-7.** Перевод на сумму свыше 50 000 ₸ подтверждается одноразовым кодом из SMS. Перевод на меньшую сумму подтверждается PIN-кодом приложения или биометрией.
* **Ф-8.** Сумма перевода и комиссия блокируются на счёте отправителя до получения финального статуса от СБМП. Если СБМП не ответил в течение 30 секунд, перевод отменяется, сумма разблокируется, клиент видит статус «Отклонён».
* **Ф-9.** Перевод отображается в истории операций с номером телефона и банком получателя, по нему можно скачать квитанцию в PDF и повторить перевод.
* **Ф-10.** Поиск получателя по номеру телефона ограничен: не более 10 запросов в минуту с одного устройства. При превышении клиент видит сообщение «Слишком много запросов, попробуйте через минуту». Ограничение защищает от массового сбора имён клиентов по номерам.

### Sequence Diagram
Приложение → сервис переводов: номер телефона. Сервис переводов → шлюз СБМП: запрос банков получателя. Шлюз СБМП → сервис переводов: список банков и имя получателя. Приложение → сервис переводов: сумма, источник списания, банк получателя. Сервис переводов → антифрод: проверка. Сервис переводов → АБС: блокировка суммы и комиссии. Сервис переводов → шлюз СБМП: платёжное поручение. Шлюз СБМП → сервис переводов: статус. Сервис переводов → АБС: списание или разблокировка. Сервис переводов → сервис push: статус перевода.

### Нефункциональные требования
* Время выполнения перевода — не более 5 секунд.
* Сервис переводов работает круглосуточно, 24/7, без плановых простоев.
* Пиковая нагрузка — до 40 переводов в секунду.

### Требования к данным
По каждому переводу хранить: идентификатор перевода, номер телефона получателя, полное ФИО получателя, банк получателя, номер карты отправителя, сумму, комиссию, статус, дату и время создания и каждого изменения статуса (UTC+5). Срок хранения — 5 лет.

### Требования к интеграции
Взаимодействие со шлюзом СБМП — по протоколу Оператора версии 2.1. При отсутствии ответа запрос в СБМП повторяется до 3 раз с интервалом 10 секунд. СБМП ежедневно недоступна с 23:50 до 00:10 (UTC+5) — регламентное закрытие операционного дня Оператора. Обработка ошибок, полученных от СБМП, — согласно Ф-11.

### Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| В текущем месяце клиент перевёл по номеру телефона 150 000 ₸ | Перевести 100 000 ₸ | Комиссия 950 ₸ |
| Номер не зарегистрирован в СБМП | Ввести номер | Сообщение «Получатель не найден» |
| Остаток на карте 2 000 000 ₸ | Перевести 1 000 000 ₸ | Перевод отклонён, сообщение «Превышен лимит на одну операцию» |
| Контрагент выбрал основной банк в СБМП | Ввести его номер | Основной банк показан первым |
